# QuotesAPI

## 📌 Overview
QuotesAPI is a Spring Boot application that sends motivational quotes via email.  
It combines software development practice with English learning, delivering daily phrases to support language growth and personal motivation.

## 🛠 Tech Stack
- Java 17, Spring Boot  
- MySQL (quotes database)  
- Spring Mail API  
- Deployed locally (development phase)

## ✨ Features
- Stores motivational quotes in MySQL  
- Sends daily quotes via email notifications  
- Simple REST API for managing quotes  
- Designed to support English learning journey

## 🚀 Setup
```bash
git clone <repo-url>
cd quotesapi
mvn clean install
java -jar target/app.jar
